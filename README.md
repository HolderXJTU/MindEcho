# MindEcho

Official repository of **“Echoes of Reality: Retrieval-Augmented Causal Invariant Learning for Brain Visual Decoding”**

MindEcho is a retrieval-augmented brain visual decoding framework for reconstructing visual stimuli from fMRI responses. It consists of three key components: **Causal-Phase Disentangler (CPD)**, **Confidence-Aware Retrieval (CAR)**, and **Phase-Semantic Fusion Generator**.

## Datasets

We evaluate MindEcho on two widely used fMRI visual decoding datasets: **Natural Scene Dataset (NSD)** and **Generic Object Decoding (GOD)**.

The NSD dataset can be downloaded from:

[https://cvnlab.slite.page/p/M3ZvPmfgU3/General-Information](https://cvnlab.slite.page/p/M3ZvPmfgU3/General-Information)

The GOD dataset can be downloaded from:

[https://github.com/KamitaniLab/GenericObjectDecoding](https://github.com/KamitaniLab/GenericObjectDecoding)

Please organize the dataset files as follows:

```text
Data/
├── NSD/
│   ├── fmri/
│   ├── images/
│   ├── captions/
│   └── metadata/
└── GOD/
    ├── fmri/
    ├── images/
    └── metadata/
```

For NSD, we follow the commonly used NSD preprocessing protocol and use visual cortex ROI responses. For GOD, we follow the standard train/test split with ImageNet categories.

## External Semantic Memory

MindEcho constructs an external visual-textual semantic memory from large-scale natural image datasets, including **MS-COCO** and **ImageNet**.

The MS-COCO dataset can be downloaded from:

[https://cocodataset.org/#download](https://cocodataset.org/#download)

The ImageNet dataset can be downloaded from:

[https://image-net.org/](https://image-net.org/)

The external memory contains pre-computed CLIP image features and CLIP text features. Dense captions are generated by a vision-language model and encoded by the CLIP text encoder.

Please put the processed memory files into:

```text
Data/Memory/
```

Expected memory format:

```text
Data/Memory/
├── memory_clip.pt
├── image_features.pt
├── text_features.pt
└── metadata.json
```

To avoid data leakage, all images overlapping with NSD/GOD stimuli should be removed before constructing the memory bank. Near-duplicate filtering is recommended using perceptual hashing and CLIP similarity.

## Pretrained Models

MindEcho is built upon several pretrained foundation models, including CLIP and Stable Diffusion.

The Stable Diffusion v1.4 model can be downloaded from:

[https://huggingface.co/CompVis/stable-diffusion-v1-4](https://huggingface.co/CompVis/stable-diffusion-v1-4)

The CLIP model can be downloaded or loaded from:

[https://github.com/openai/CLIP](https://github.com/openai/CLIP)

or

[https://github.com/mlfoundations/open_clip](https://github.com/mlfoundations/open_clip)

Please put pretrained model files into:

```text
pretrained/
├── stable-diffusion-v1-4/
├── clip/
└── controlnet/
```

## Environment

We recommend using Python 3.10 and PyTorch.

```bash
conda create -n mindecho python=3.10 -y
conda activate mindecho
pip install -r requirements.txt
```
